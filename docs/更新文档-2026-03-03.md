# DI-Viewer 更新文档（2026-03-03）

## 一、发布与构建

- 新增 GitHub Actions 桌面端构建发布流程。
- 构建矩阵覆盖：
  - `windows-x64`
  - `macOS arm64`
- 产物类型调整为安装包优先：
  - Windows：`exe`、`msi`
  - macOS：`dmg`
- 仅在 `v*` 标签触发 Release 发布。
- 若存在 `docs/releases/<tag>.md`，自动作为对应 Release Notes。
- 发布时额外生成 `SHA256SUMS` 校验文件。
- 当前阶段保持 unsigned（未接入签名/公证）。

## 二、图标与资源

- 项目已切换为应用正式图标资源。
- CI/CD 不再动态编译图标资源，直接使用仓库内已准备好的 icon 文件。

## 三、界面与交互（侧边状态条）

- 重构为「窄状态条 + 悬浮展开图标列」交互。
- 展开态与面板标题统一显示应用图标。
- 移除不协调的点击内阴影效果，优化视觉一致性。
- 字体已替换为更统一的组合（含中文字体兜底）。

## 四、主题与设置

- 增加状态条颜色主题切换能力（多主题）。
- 颜色切换入口已放入设置页（快捷键/设置页），不再放在顶部菜单。
- 主题联动范围扩展为：
  - 左侧状态条
  - 展开后的菜单面板（边框、背景、按钮、输入框等）

## 五、功能修复

- 修复主页快捷控制按钮（显示/隐藏、置顶、穿透、透明度、最大化/最小化等）在浏览页不生效问题。
- 根因修复：
  - 调整 Tauri capability 配置，允许 `browser*` 窗口与远程页面使用 IPC 能力。
  - 增加 `invoke` 兼容逻辑（`__TAURI__` / `__TAURI_INTERNALS__` 双通道兜底）。

## 六、说明

- 快捷键默认值已恢复为原方案（未强制改为新组合键）。
- 本文档对应本地联调版本，若后续再改发布策略或权限策略，请同步追加记录。
