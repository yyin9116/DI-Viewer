# DI-Viewer v1.1.21

## Fix

- **修复安装版启动即崩溃（退出码 101）**：打包器会把资源路径里的每级 `..` 压成一层
  `_up_` 目录，`../../shared/dist` 实际安装在 `<安装目录>\_up_\_up_\shared\dist\`，
  而 shared shell 的资源解析只探测了 `<安装目录>\shared\dist` 与 `<安装目录>\dist`，
  安装版（NSIS/MSI）启动时找不到 `assets/app.css` 直接 panic。
  现在按 0~2 级 `_up_` 深度探测，dev / NSIS / MSI 三种形态全部覆盖。
- **应用图标与界面 Logo 统一**：按侧栏 Logo（竖条 + 半圆盘 + 圆点，slate-700）重新
  生成全套图标（ico / icns / png / Store Logo），任务栏、窗口、安装器图标同步更新。

## Packages

- `DI-Viewer-v1.1.21-windows-x64-setup.exe`：NSIS 安装器（推荐，用户级安装）。
- `DI-Viewer-v1.1.21-windows-x64.msi`：MSI 安装包（企业部署）。
- `DI-Viewer-v1.1.21-windows-x64-portable.zip`：**免安装便携版**，解压后直接运行
  `DI-Viewer.exe`（需系统已装 WebView2 Runtime；不写注册表、无卸载项，删除文件夹即卸载）。
- `DI-Viewer-v1.1.21-macos-arm64.dmg`：macOS 安装镜像。
