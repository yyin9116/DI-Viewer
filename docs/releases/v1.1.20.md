## Window stability and start page fit

- Persists browser window geometry in logical pixels (scale-factor aware), guards against minimized/phantom coordinates (-32000) and zero-size writes, and debounces rapid resize events so window position/size survive restarts reliably.
- Replaces WebView2's default additional browser arguments wholesale with an explicit set that keeps `msWebOOUI`/`msPdfOOUI`/`msSmartScreenProtection` disabled and adds `--disable-gpu-sandbox --no-sandbox`, fixing GPU-process hangs ("msedgewebview2 has stopped working") on dual-AMD-GPU Windows machines.
- Hides start page scrollbars and auto-fits the window to the start page (1220x760), centering it on the current monitor on launch and when returning home.
- Corrects version metadata across package/config/crate (previously stuck at 1.1.0) and restores the garbled "录制" label in the recording source picker.
