# DI-Viewer v1.1.14

本次更新聚焦于桌面端稳定性、侧边栏交互与发布流程完善。

## 主要更新

- 重构侧边状态条交互：
  - 收缩为细竖条，悬浮展开为图标列
  - 优化展开态视觉与动画，统一菜单层级风格
- 菜单与面板主题联动：
  - 支持状态条颜色切换
  - 颜色切换入口移动到设置页
  - 状态条与展开菜单配色同步
- 主页快捷控制修复：
  - 修复显示/隐藏、置顶、穿透、透明度、最大化/最小化等按钮失效问题
  - 修复注入页面桥接调用兼容性（`__TAURI__` / `__TAURI_INTERNALS__`）
  - 修复 Tauri capability 对浏览窗口与远程页面的授权范围
- 图标与资源整理：
  - 使用已准备好的应用图标资源
  - CI/CD 不再动态编译 icon 资源

## CI/CD 与发布

- GitHub Actions 桌面发布流程持续使用：
  - Windows x64：`exe`、`msi`
  - macOS arm64：`dmg`
- 自动附带 `SHA256SUMS`。
