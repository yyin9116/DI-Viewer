# DI-Viewer v1.1.16

本次更新聚焦于 Tauri 浏览器壳的安全边界、启动体验与前端控制条一致性。

## 主要更新

- 新增打包内置的 Lucid Start Page：
  - Tauri 启动时默认进入本地资源主页
  - 搜索、快捷入口、最近访问与主题切换在本地页内可用
- 重构共享浏览器控制壳：
  - 使用共享 React UI 替代旧的 `inject.css` / `inject.html` / `inject.js`
  - 左侧控制条可注入到外部网页，打开远程页面后仍可使用导航、收藏、媒体和全屏控制
  - 折叠态控制条恢复为简洁竖条，并随夜间模式切换黑白样式
- 优化主页与控制台联动：
  - 夜间模式在主页和控制壳之间同步
  - 修复搜索引擎按钮、主题图标和顶部 tab 栏遮挡问题
  - 展开态侧栏顶部折叠按钮和底部设置按钮固定，中间工具按钮居中
- 收窄 Tauri 安全能力：
  - 关闭全局 Tauri 注入
  - 移除远程页面的宽泛 capability
  - 改为通过显式 `__diviewer_bridge` 暴露受控命令
- 改进桌面启动与构建链路：
  - Tauri dev/build 前自动构建共享 UI
  - 本地 start page 随 Tauri 资源一起打包
  - 调整内置浏览 UA，降低部分站点误判浏览器版本过低的概率

## 产物

- Windows x64：`exe`、`msi`
- macOS arm64：`dmg`
