# DI-Viewer v1.1.23

## New

- **一键沉浸（`Ctrl+Alt+I`）**：按一次，五项同时生效——去掉系统标题栏与边框、
  收起侧栏（顶栏随之整条消失）、开启点击穿透、置顶、锁定位置；再按一次全部还原。
  进入前把五项状态存成快照（`immersive_restore`），退出时逐项回放，所以它是**开关**而不是
  **重置**：进入前本来就置顶的，退出后仍然置顶。
  - 应用顺序有讲究：进入时穿透放最后（之后窗口不再接收光标，任何后续调用都点不到），
    退出时穿透先解除、快照最后清除（中途失败还能重试）。
  - **崩溃安全**：沉浸态下被强杀，下次启动会在首帧显示前自动解绕，不会留下一个
    无边框 + 穿透 + 锁位、点不动的窗口。实测 `taskkill /F` 后重启 →
    `borderless false / inside false / locked false / 侧栏 true`、`immersive_restore: null`，
    非客户区从 `16x9` 复原成 `16x39`。
  - 该键必须在窗口穿透后仍可按下，因此列入「必须带修饰键」的全局热键组。
- **无边框可单独开关**：设置 → 窗口 → 「无边框」，隐藏系统标题栏与边框。
  拖动手势随之转到外壳顶部条：无边框时按下顶部条转成原生拖动，但**排除**
  `button / input / a / textarea / select / [data-no-drag]`——标签仍然可以拖拽重排。

## Fix

- **修复部分网页出现多条嵌入态 bar**：WebView2 的初始化脚本在**每一个 frame**（含
  iframe）都会执行，遇到大量 iframe 嵌入的页面就会把外壳重复挂载一遍，页面上每隔一段
  出现一条 chrome。现脚本首行判断 `window.top !== window` 直接早退（跨域帧里
  `window.top` 也安全可读），并加 `__diviewerShellBooted` 幂等标记覆盖 bfcache 恢复与
  二次初始化。实测 4 个 srcdoc iframe 全部 `roots 0 / mounts 0 / booted false`，
  顶层 `roots 1`。
- **旧热键配置不再整体丢失**：新增的 `immersiveMode` 字段若用普通 `serde` 反序列化，
  旧 `hotkeys.json` 缺这一项会导致整个文件解析失败、被静默丢弃，用户自定义的绑定全没了。
  已改为 `#[serde(default = ...)]` 并补回归测试（缺 `immersiveMode` 的 JSON 反序列化后
  其余绑定原样保留）。

## Changed

- **标签胶囊改为扁平**：去掉激活态的 ring 与投影（`shadow-[0_0_0_1px_...,0_1px_1px_...]`），
  改成与周围 chrome 同色的 1px 边框。**所有**标签都带边框，未激活时为 `transparent`
  ——否则激活瞬间会因边框出现而位移 1px。实测激活 `1px rgb(42,42,48)` 且 `box-shadow: none`，
  其余标签 `1px rgba(0,0,0,0)`。
- **收起态把手自动隐藏**：它正压在左边缘正中，也就是播放器控件与字幕的位置，常驻太碍事。
  现改为**位置驱动 + 短延时**：指针进入左侧 26px 边缘区立刻唤出；指针离开该区域后收回
  （左移 28px + 透明），首次收起保留 2.6s 可发现期。刻意没有用「每次鼠标移动都续命」的
  全局 idle 计时器——那样在页面中间拖动指针时，把手会在画面上亮好几秒，正是最糟的情况。
  实测：收起瞬间 `opacity 1.00` → 静置 2.7s `0.00`；指针在 x=400 保持 `0.00`；
  移到 x=6 立刻 `1.00`。
- 沉浸态的 `borderless` / `immersive` 已进 `get_state`，设置面板与状态栏可读到。

## Notes

- 「无边框」不能靠窗口样式位判断：tao 的 `set_decorations(false)` 保留 `WS_CAPTION`，
  真正生效靠拦截 `WM_NCCALCSIZE` 把非客户区清零。判断是否无边框请用
  `GetWindowRect` 与 `GetClientRect` 的几何差（本机：有边框 `16x39`，无边框 `16x9`，
  差的正是 30px 标题栏）。
- 顶栏整条只在侧栏展开时渲染，所以「收起侧栏顶栏」本来就是一个动作，快照里只记侧栏状态。
