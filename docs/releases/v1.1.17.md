# DI-Viewer v1.1.17

本次更新修复 `v1.1.16` 的云端发布构建失败，并继续包含 Tauri 浏览器壳更新。

## 构建修复

- 修复 GitHub Actions 中 shared UI 未安装依赖导致 `vite` 找不到的问题。
- 修复 Windows runner 中 Tauri 包装脚本执行 `npm` 时触发 `spawn EINVAL` 的问题。
- 发布流程现在会同时缓存并安装 `tauri-di-viewer` 与 `shared` 的 npm 依赖。

## 主要更新

- 新增打包内置的 Lucid Start Page。
- 使用共享 React UI 替代旧的静态注入文件。
- 外部网页打开后仍保留左侧控制条、导航、收藏、媒体和全屏控制。
- 主页与控制壳夜间模式联动。
- 修复搜索引擎按钮、主题图标、顶部 tab 栏遮挡和侧栏布局问题。
- 收窄 Tauri capability，关闭全局 Tauri 注入，改用受控 bridge。

## 产物

- Windows x64：`exe`、`msi`
- macOS arm64：`dmg`
